# 中1 英単語10

iPhone向け・毎日10問の4択英単語Webアプリです。

## GitHub Pages 公開
1. GitHubで新しいリポジトリを作成
2. このフォルダ内の `index.html`, `words.js`, `manifest.webmanifest`, `sw.js` をアップロード
3. Settings → Pages → Deploy from a branch
4. Branch を `main` / `(root)` にして Save
5. 表示されたURLをiPhoneのSafariで開く
6. Safariの共有 →「ホーム画面に追加」

## 出題
- 日本語→英語 / 英語→日本語を半々
- 1日10問
- 間違えた単語を優先復習
- 10月以降 / 9月まで復習 / 全部 の範囲切替
- 学習履歴は localStorage に保存

## 単語について
初版は中1の一般的な語彙を Here We Go! 1 の学習テーマ・進行に沿って独自に整理したスターター版です。
学校配布の「単語プリント」の写真があれば、次版で学校の出題語にさらに正確に合わせられます。
