1. このZIPを解凍します。
2. GitHubで既存の english リポジトリを開き、Pagesで公開中のブランチ（通常 main）を選びます。
3. Add file → Upload files を選びます。
4. 解凍した中の index.html / app.js / words.js / kanji.js / sw.js / manifest.webmanifest / README.txt をまとめてアップロードします。
   フォルダ自体やZIPをアップロードせず、既存の index.html と同じ階層にファイルを置いてください。
   Pagesが /(root) 公開の場合はリポジトリ直下です。/docs 公開の場合は docs 内に置きます。
5. Commit changes を押します。既存の同名ファイルが置き換わります。
6. 公開の更新が完了してから、今までと同じURLを開きます。
   古い表示が残る場合は一度再読み込みし、アプリのタブやホーム画面アプリをすべて閉じて開き直してください。
   ブラウザのサイトデータは削除しないでください（履歴も消えてしまいます）。

【漢字モードを追加しました】
・画面上部の「英単語」「漢字の読み」で教科を切り替えます。
・漢字は、漢字・送り仮名を見てひらがなの読みを選ぶ4択10問です。
・「漢字の読み」と「苦手な漢字の復習」の2モードです。
・中1向け仮練習50語を収録。テスト範囲も中1の新出漢字も未照合です。
・国語の試験日は未設定です。英語の試験日を国語に流用していません。
・英語と漢字の学習日数・正答率・履歴・苦手語は分けて保存します。
・学習データのバックアップには英語と漢字の両方が含まれます。
・後日、漢字・英単語の範囲画像を確認して出題データを差し替えられます。
・今回のZIP内の7ファイルを既存の index.html と同じ階層へアップロードします。

【使い方（英語）】
・起動時は必ず「後期中間テスト対策」。上部の4つのボタンで変更できます。
・各モードの「今日の10問を始める」を押します。4択で回答し、「次の問題」で進みます。
・日本語→英語5問、英語→日本語5問。終了すると結果を表示します。
・同じ日の途中なら、モードを切り替えたり画面を閉じたりしても「続きから再開」できます。
・10問完了後は「もう10問練習する」で追加学習できます。履歴は各回を記録します。
・苦手語が0語のときは苦手復習の出題を行いません。他のモードで学習してください。
・苦手語が10語未満のときは同じ語を繰り返して10問にします。
・「学習履歴を見る」「苦手単語を確認する」で記録を確認できます。
・「学習データをバックアップ」でJSONを保存できます（この版にはJSONを戻す画面はありません）。

元ファイルは公開中の https://hagiwara-takashi.github.io/english/ から取得しました。
元のZIPは作業環境にありませんでした。既存の164語を保持しています。
